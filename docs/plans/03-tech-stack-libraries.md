# 03. Технологический стек и библиотеки (.NET 10)

Для реализации системы подобраны библиотеки, обеспечивающие максимальную производительность, безопасность и кроссплатформенность в экосистеме .NET 10.

---

### Сводная таблица библиотек

| Область | Рекомендуемая библиотека | Обоснование выбора |
| :--- | :--- | :--- |
| **Кроссплатформенный UI** | `Avalonia` (11.x+) | Полноценный GUI для Windows, macOS, Linux и браузера (WebAssembly). Единая XAML кодовая база без браузерных оберток вроде Electron. |
| **UI MVVM Framework** | `CommunityToolkit.Mvvm` | Быстрый реактивный MVVM на Source Generators (высокая производительность в Native AOT и WebAssembly). |
| **Транспорт UI ↔ Gateway** | `Grpc.Net.Client`, `Grpc.Net.Client.Web` | Бинарная сериализация Protobuf, высокая скорость, двунаправленный gRPC Streaming для стриминга мыслей/логов агента в UI, поддержка mTLS. |
| **Шина сообщений** | `MassTransit` + `MassTransit.RabbitMQ` | Индустриальный стандарт .NET: персистентные очереди, подтверждения доставки (Publisher Confirms / Acks), Outbox Pattern, DLQ. |
| **AI Абстракции** | `Microsoft.Extensions.AI` | Официальный стандарт Microsoft в .NET для чат-моделей, эмбеддингов, конвейеров middleware (логирование, кэширование, rate limiting). |
| **Агентные шаблоны** | `Microsoft.SemanticKernel` / Custom ReAct | Реализация циклов рассуждений агентов, динамического контекста и генерации предложений (Proposals). |
| **Поддержка инструментов** | `ModelContextProtocol.NET` | Протокол MCP от Anthropic для стандартизированного подключения любых внешних тулов. |
| **Изолированное исполнение** | `Docker.DotNet` + `CliWrap` | Управление контейнерами Docker для ненадежного кода и надежный запуск локальных CLI процессов с таймаутами и перехватом потоков вывода. |
| **AST-анализ PowerShell** | `System.Management.Automation` | Официальный парсер Microsoft для глубокого анализа абстрактного синтаксического дерева PowerShell-скриптов. |
| **Базы данных и Outbox** | `Npgsql.EntityFrameworkCore.PostgreSQL` / `Microsoft.Data.Sqlite` | Хранение сессий, состояний агентов, неизменяемых аудит-логов и таблиц Transactional Outbox. |
| **Векторная память** | `pgvector` / `QdrantClient` | Долговременная семантическая память, профили агентов и RAG-поиск по артефактам. |
| **Аудит и трассировка** | `Serilog` + `OpenTelemetry` | Структурированное логирование и распределенная трассировка всех решений безопасности и токенов LLM. |
