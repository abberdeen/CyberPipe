# 03. Технологический стек и библиотеки (.NET 10)

Стек подобран по критериям **максимальной скорости отклика, минимального потребления памяти, простоты развертывания (Zero-Dependency Startup)** и **радикальной экономии токенов** в .NET 10. Из стека исключены тяжеловесные внешние сервисы (обязательный RabbitMQ, PostgreSQL), которые усложняли запуск и добавляли сетевые задержки.

---

### Сводная таблица библиотек и их роли

| Область | Рекомендуемая библиотека | Обоснование и решаемая задача |
| :--- | :--- | :--- |
| **Внутрипроцессная шина (Fast Bus)** | `System.Threading.Channels` (Встроено в .NET 10) | Ультрабыстрая неблокирующая передача сообщений внутри процесса (< 0.05 мс) с поддержкой Backpressure (`BoundedChannel`) и приоритетного канала отмены (`Kill-Switch`). |
| **Локальная БД и Очередь задач** | `Microsoft.Data.Sqlite` + `Dapper` / `EF Core` (WAL mode) | Надежное локальное хранение без установки внешних СУБД. Сохранение чекпоинтов задач на паузе, локального семантического кэша и учета расходов токенов. |
| **Telegram-интеграция** | `Telegram.Bot` | Быстрый клиент Telegram API (Long Polling / Webhook), поддержка Inline-кнопок для подтверждения бюджета (`[▶️ Продолжить]`, `[🛑 Стоп]`) и жесткая фильтрация по `UserId`. |
| **Локальный Семантический Роутер (Tier 1)** | `Microsoft.ML.OnnxRuntime` + `System.Numerics.Tensors` | Запуск крошечной мультиязычной модели эмбеддингов (`multilingual-e5-small` / `bge-micro`) локально на CPU за ~5–10 мс + аппаратное SIMD-вычисление косинусной близости (`TensorPrimitives`). **0 токенов на распознавание команд!** |
| **Локальная Микро-LLM (Tier 2)** | `OllamaSharp` / `Microsoft.Extensions.AI.Ollama` | Подключение локальной легкой модели (1.5B–3B, например Qwen2.5-3B) для бесплатного парсинга параметров команд, если запрос не попал в Tier 0/1. |
| **AI Пайплайн и Контроль Токенов** | `Microsoft.Extensions.AI` + `Microsoft.ML.Tokenizers` | Единый конвейер вызовов LLM со встроенным middleware **`TokenBudgetMiddleware`** (точный подсчет токенов через `TiktokenTokenizer` *до* отправки запроса в облако, кэширование префиксов, обрезка контекста). |
| **Безопасное управление Аудио и Медиа Хоста** | `NAudio` (Windows CoreAudio) + Системные Media-контроллеры | Программное управление громкостью с жестким потолком (`Volume Clamp`), проверка активного аудиоустройства (наушники vs колонки), отправка безопасных медиа-команд (`Play/Pause/Next`) без запуска Raw Shell. |
| **Кроссплатформенный UI** | `Avalonia` (11.x+) + `CommunityToolkit.Mvvm` | Нативный быстрый GUI (Desktop/Web) без прожорливого Electron. Быстрый MVVM на Source Generators. |
| **Транспорт UI ↔ Daemon** | `Grpc.Net.Client` / `Grpc.AspNetCore` | Быстрый бинарный стриминг метрик, логов, расходов токенов и кнопок управления в реальном времени. |
| **Бэкенды песочниц (для Tier 3)** | `CliWrap`, `Wasmtime`, `Docker.DotNet` | • `CliWrap` — легкие процессы ОС с жестким `CancellationToken` и лимитами.<br>• `Wasmtime` — мгновенная изоляция скриптов/плагинов.<br>• `Docker.DotNet` — опционально для тяжелых задач кодинга. |
| **AST-анализ и защита от вайпа** | `System.Management.Automation` + Кастомный `HostSafetyGuard` | Синтаксический разбор скриптов PowerShell/Bash + жесткий блокировщик деструктивных команд (`rm -rf`, `Format-Volume`, реестр) и фильтр 18+ / NSFW контента. |
| **Защита секретов и Очистка данных** | `System.Security.Cryptography` (`DPAPI` / `AES-256-GCM`) + `Sanitizer` | Локальное аппаратное шифрование ключей API и секретов на диске; автоматическое вырезание секретов (`[REDACTED]`) перед отправкой в облачные LLM и логи. |
| **Управление памятью и Кэширование** | `System.Buffers` (`ArrayPool<T>`) + `MemoryCache` (`SizeLimit`) | Нулевые лишние аллокации при чтении потоков и строгий потолок потребления ОЗУ кэшем. |
| **Аудит и трассировка** | `Serilog` + `OpenTelemetry` | Быстрое асинхронное логирование (после очистки секретов) с учетом стоимости каждого запроса в токенах и долларах. |
