# Assumptions, Open Questions, and Architecture Validation Test Plan

> **Document Role:** Consolidates all architectural assumptions (`ASSUMPTION-001`..`ASSUMPTION-012`), unresolved stakeholder/design questions (`OQ-01`..`OQ-10`), and the executable Phase 0/1 Architecture Validation Test Suite (`TEST-001`..`TEST-015`).

---

## 1. Explicit Architectural Assumptions (`ASSUMPTION-001` .. `ASSUMPTION-012`)

Per Section 10 of the architecture review mandate, every implicit assumption in `docs/plans/` is surfaced below along with the impact if the assumption proves false and the test that validates it.

| ID | Assumption Statement | Source in `docs/plans/` | Impact if False | Validation Test |
| :--- | :--- | :--- | :--- | :--- |
| **`ASSUMPTION-001`** | `.NET 10.0` SDK and runtime (`net10.0`) are installed on the developer and target host machines, and all selected NuGet libraries support `net10.0` (or `net8.0`/`net9.0` forward compatibility). | [`03-tech-stack-libraries.md`](../../plans/03-tech-stack-libraries.md) | Solution fails to compile or Native AOT (`CyberPipe.Cli`) fails trimming. | `TEST-001`, `TEST-013` |
| **`ASSUMPTION-002`** | `SQLitePCLRaw.bundle_e_sqlcipher` (v2.1.10+) compiled for Windows/Linux/macOS includes the **`ENABLE_FTS5`** compile-time flag required by `HybridKnowledgeStore` (`knowledge.db`). | [`09-data-protection-and-state-hub.md`](../../plans/09-data-protection-and-state-hub.md) | Full-text search (`FTS5`) creation fails with `no such module: fts5` on encrypted databases (`RISK-002`). | `TEST-002` |
| **`ASSUMPTION-003`** | `CyberPipe.exe` runs inside an interactive Windows user session (`Session >= 1`) started via a Task Scheduler Logon Task rather than a `Session 0` Windows Service. | [`10-sandbox-telemetry-and-heuristics.md`](../../plans/10-sandbox-telemetry-and-heuristics.md), [`15-cli-and-execution-modes.md`](../../plans/15-cli-and-execution-modes.md) | CoreAudio volume clamping (`VolumeClamp`), GSMTC media keys, user idle detection, and `CurrentUser` `DPAPI` fail in `Session 0`. | `TEST-014` |
| **`ASSUMPTION-004`** | Standard non-elevated Windows users can create Job Objects (`CreateJobObject`), Restricted Tokens (`CreateRestrictedToken`), and set NTFS `Deny` ACLs on directories they own (`%LOCALAPPDATA%\CyberPipe\data\`). | [`10-sandbox-telemetry-and-heuristics.md`](../../plans/10-sandbox-telemetry-and-heuristics.md) | If an API requires `SeAssignPrimaryTokenPrivilege` or admin elevation (e.g., certain `CreateAppContainerProfile` configurations), `Brainstem` startup fails without admin rights (`RISK-006`). | `TEST-004` |
| **`ASSUMPTION-005`** | Local CPU inference of `all-MiniLM-L6-v2.onnx` (quantized INT8/FP32) via `Microsoft.ML.OnnxRuntime` completes in **`< 15 ms`** (`p95`) on a standard modern desktop/laptop CPU without a discrete GPU. | [`10-sandbox-telemetry-and-heuristics.md`](../../plans/10-sandbox-telemetry-and-heuristics.md) | `Tier 1` routing exceeds its `15 ms` budget (`RISK-015`). | `TEST-007` |
| **`ASSUMPTION-006`** | Cosine similarity thresholds of `0.82` (`L1 SemanticIntentCache`) and `0.92` (`L2 SemanticResponseCache`) on `all-MiniLM-L6-v2` embeddings yield `< 1%` false-positive intent/response collisions across multilingual (EN/RU) queries. | [`10-sandbox-telemetry-and-heuristics.md`](../../plans/10-sandbox-telemetry-and-heuristics.md) | Users receive wrong cached answers for distinct questions (`SP-03`) or `all-MiniLM-L6-v2` (primarily English-trained) degrades on Russian queries (`OQ-04`). | `TEST-007` |
| **`ASSUMPTION-007`** | Pre-compiling `Netrunner` C# scripts on the host into a self-contained `.dll` (or `.wasm` module) allows the child sandbox worker to execute within a **`64 MB`** Job Object memory limit (`RISK-003`). | [`ADR-0007`](../05-adr/0007-proactive-scheduling-and-netrunner-dag-engine.md) | If the base .NET 10 CoreCLR runtime overhead in the child worker exceeds `64 MB` virtual/committed memory, the Job Object limit must be tuned to `96–128 MB` or use Native AOT / `Wasmtime`. | `TEST-003` |
| **`ASSUMPTION-008`** | A single SQLite WAL writer per subsystem database (`9` `.db` files total) with `Cache=Private` and `busy_timeout=5000` handles all concurrent daemon workloads without `SQLITE_BUSY` timeouts. | [`09-data-protection-and-state-hub.md`](../../plans/09-data-protection-and-state-hub.md), [`ADR-0003`](../05-adr/0003-decentralized-sqlite-and-sqlcipher-encryption.md) | High-frequency telemetry or outbox bursts could still cause transient lock waits if transactions are held open across async I/O. | `TEST-002` |
| **`ASSUMPTION-009`** | Local `Ollama` (or `LlamaSharp`) is available on the host machine when `TokenBudgetGovernor` pauses cloud LLMs at `100%` daily spend (`REQ-009`), or the system gracefully degrades to `Tier 0/1` deterministic skills if no local LLM is installed. | [`13-model-advisor-and-tier-configuration.md`](../../plans/13-model-advisor-and-tier-configuration.md) | On a low-RAM laptop (`8 GB` RAM) without `Ollama`, `Tier 2/3` queries will return a friendly "Cloud budget exhausted & no local model configured" message rather than an LLM synthesis. | `TEST-010` |
| **`ASSUMPTION-010`** | Other non-sandboxed applications running natively under the Owner's interactive Windows user account are trusted by the Owner (`TB-02`). | [`05-security-agent.md`](../../plans/05-security-agent.md) | Malware already running as the Owner's OS user can access `CurrentUser` `DPAPI` and Contour 1 Named Pipes. | `TEST-006` |
| **`ASSUMPTION-011`** | `QuestPDF` Community License (`< $1M USD` annual gross revenue) and `Hangfire.Core` (`LGPL v3` dynamic linking without source modification) are acceptable for CyberPipe's personal/open-source distribution model. | [`03-tech-stack-libraries.md`](../../plans/03-tech-stack-libraries.md) | Commercial enterprise redistribution would require commercial licenses or replacing `Hangfire` with `Cronos` + custom UI (`RISK-005`). | `TEST-013` |
| **`ASSUMPTION-012`** | Windows `TerminateJobObject` and socket disposal can consistently complete within **`< 50 ms`** (`p99`) when triggered by the priority `/stop` handler (`REQ-004`). | [`14-fault-isolation-and-resilience.md`](../../plans/14-fault-isolation-and-resilience.md) | Kernel driver hangs in audio/GPU libraries inside a worker could delay process handle cleanup slightly beyond `50 ms`. | `TEST-008` |

## 2. Unresolved Open Questions Requiring Stakeholder / Engineering Alignment (`OQ-01` .. `OQ-10`)

| ID | Open Question | Affected Documents / Components | Recommended Default Decision in `arch-argon` |
| :--- | :--- | :--- | :--- |
| **`OQ-01`** | **Should `MassTransit` v8 (`Apache 2.0`) be retained with a custom SQLite Outbox, or replaced entirely with `.NET` `System.Threading.Channels` + Dapper Outbox?** (`RISK-001`) | `CyberPipe.Core`, `CyberPipe.State` (`ADR-0002`) | Retain `MassTransit` `8.x` (`< 9.0.0`) + Dapper SQLite Outbox in `masstransit.db` for MVP; revisit before late-2026 v8 EOL. |
| **`OQ-02`** | **Should `Hangfire.Core` (`LGPL v3`) be kept with a custom Dapper/SQLCipher `JobStorage`, or replaced with `Cronos` + a lightweight SQLite scheduler table?** (`RISK-005`) | `CyberPipe.Scheduling` (`ADR-0007`) | Ban `Hangfire.Storage.SQLite`; implement a Dapper/SQLCipher store in `hangfire.db` (or use pure `Cronos` if LGPL v3 is undesired). |
| **`OQ-03`** | **Should `Netrunner` scripts pre-compile to restricted .NET `.dll` assemblies or `Wasmtime` (`.wasm`) modules to meet the `64 MB` sandbox cap?** (`RISK-003`) | `CyberPipe.Netrunner`, `CyberPipe.Sandbox` (`ADR-0007`) | Pre-compile `main.csx` on the host during `NetrunnerPackageValidator` into a restricted `.dll` (with `Wasmtime` `.wasm` as an optional Phase 2 engine). |
| **`OQ-04`** | **Is `all-MiniLM-L6-v2` (English-centric) sufficient for `Tier 1` semantic routing if the Owner speaks Russian + English, or should `multilingual-e5-small` be used?** (`ASSUMPTION-006`) | `CyberPipe.Cognition` (`ADR-0001`) | Make the ONNX embedding model path configurable in `appsettings.json` and benchmark both `all-MiniLM-L6-v2` and `multilingual-e5-small` (`384-d`) in `TEST-007`. |
| **`OQ-05`** | **How should `CyberPipe.Cli` support `--offline` commands (`cyberpipe vault set --offline`) without bloating the thin Native AOT binary?** (`05-building-block-view.md` §5.2) | `CyberPipe.Cli`, `CyberPipe.Host` | Delegate `--offline` commands from `cyberpipe.exe` to `CyberPipe.exe --oneshot <args>` so `CyberPipe.Cli` only references `CyberPipe.Contracts`. |
| **`OQ-06`** | **What is the canonical installation path on Windows (`C:\Program Files\CyberPipe\` vs `%LOCALAPPDATA%\Programs\CyberPipe\`)?** (`RISK-013`) | `CyberPipe.Host`, Installer | Default to `%LOCALAPPDATA%\Programs\CyberPipe\` for per-user non-admin side-by-side updates. |
| **`OQ-07`** | **What are the exact cloud model IDs intended in [`13-model-advisor-and-tier-configuration.md`](../../plans/13-model-advisor-and-tier-configuration.md) where speculative `Meta Muse Spark / Muse Loom` names appear?** (`RISK-016`) | `CyberPipe.Cognition` (`ModelRouter`) | Treat all model identifiers as configuration data in `appsettings.json` (`Anthropic`, `OpenAI`, `Gemini`, `Ollama`) behind `IChatClient`. |
| **`OQ-08`** | **Should `VolumeClamp` (`<= 60%` day / `<= 25%` night) clamp upward-only changes or forcefully lower existing user volume if the user manually set it to `80%`?** (`QAS-014`) | `CyberPipe.Hardware` (`MediaController`) | Default to clamping **all CyberPipe-initiated volume changes** to `<= 60%/25%`, plus an explicit `EnforceCeilingOnPlayback` guard before TTS output. |
| **`OQ-09`** | **Are Linux (`bubblewrap`) and macOS (`sandbox-exec` / EndpointSecurity) required for MVP launch, or is Windows 11 the sole Phase 0/1 target?** (`RISK-006`) | `CyberPipe.Sandbox` (`ADR-0004`) | Scope Phase 0–2 strictly to **Windows 11 (`x64`/`ARM64`)**; gate Linux/macOS behind Phase 3 platform parity tests. |
| **`OQ-10`** | **What is the maximum committed memory limit for a `.NET 10` child process inside a Windows Job Object (`JOBOBJECT_EXTENDED_LIMIT_INFORMATION.ProcessMemoryLimit`)?** (`ASSUMPTION-007`) | `CyberPipe.Sandbox` (`TEST-003`) | Measure empirical `.NET 10` CoreCLR vs Native AOT minimal process commit charge in `TEST-003`; if CoreCLR base commit exceeds `48 MB`, compile the Netrunner sandbox runner as Native AOT or adjust the Job Object cap to `96 MB`. |

## 3. Executable Architecture Validation Test Plan (`TEST-001` .. `TEST-015`)

Every architectural risk (`RISK-001`..`RISK-016`), quality scenario (`QAS-001`..`QAS-014`),threat mitigation (`MIT-01`..`MIT-12`), and ADR (`ADR-0001`..`ADR-0008`) maps to one or more of the 15 concrete verification tests below.

| Test ID | Test Name & Target Project | Validates (`REQ` / `QAS` / `RISK` / `THREAT` / `ADR`) | Concrete Execution Procedure & Pass Criteria |
| :--- | :--- | :--- | :--- |
| **`TEST-001`** {#test-001} | **NuGet Graph & `masstransit.db` Outbox Crash-Recovery Test** (`CyberPipe.Integration.Tests`) | `REQ-008`, `RISK-001`, `THREAT-015`, `ADR-0002` | 1. Assert `Directory.Packages.props` contains zero references to non-existent `MassTransit.SqlTransport.Sqlite` and pins `MassTransit < 9.0.0`.<br>2. Publish 50 events to `masstransit.db` Outbox, abort host after 25, restart, and assert **all 50 events are delivered once** (`0` lost, `0` duplicates). |
| **`TEST-002`** {#test-002} | **SQLCipher Header, `FTS5`, `Cache=Private` Concurrency & `PRAGMA rekey` Self-Test** (`CyberPipe.Security.Tests`) | `REQ-007`, `QAS-006`, `RISK-002`, `RISK-008`, `RISK-014`, `THREAT-006`, `ADR-0003` | 1. Open all 9 `.db` files via `SubsystemDatabaseManager`, write data, checkpoint WAL, and assert raw file bytes `[0..15] != "SQLite format 3\0"`.<br>2. Assert `SELECT sqlite_compileoption_used('ENABLE_FTS5') == 1` and `PRAGMA cipher_version` is non-empty.<br>3. Run 8 concurrent readers + 2 writers under `Cache=Private` with `0` `SQLITE_LOCKED` errors.<br>4. Run `PRAGMA rekey` across all 9 DBs and restore from an `Argon2id` recovery kit (`RISK-014`). |
| **`TEST-003`** {#test-003} | **`Netrunner` Pre-Compiled `64 MB` Sandbox & Domain-Allowlisted Proxy Test** (`CyberPipe.Sandbox.Tests`) | `REQ-013`, `QAS-011`, `RISK-003`, `THREAT-011`, `THREAT-012`, `ADR-0007` | 1. Validate a 6-file Netrunner package with `NetrunnerPackageValidator`, asserting forbidden `System.Reflection`/`DllImport` scripts fail compilation.<br>2. Execute the pre-compiled package inside a `64 MB` Windows Job Object and assert peak committed memory `< 48 MB` (`0` OOM).<br>3. Attempt HTTP calls to `127.0.0.1:5080`, `192.168.1.1`, and `evil.com`, asserting `100%` rejection by `AllowedDomainHttpDelegatingHandler`. |
| **`TEST-004`** {#test-004} | **`Brainstem` OS Isolation (`Deny` `./data/` ACL), `8 MB` Frame Guard & `50 MB` PDF Bomb Test** (`CyberPipe.Sandbox.Tests`) | `REQ-002`, `REQ-015`, `QAS-005`, `QAS-010`, `RISK-006`, `THREAT-008`, `THREAT-009`, `THREAT-010`, `ADR-0004` | 1. Spawn `CyberPipe.Brainstem.exe` from a user folder outside `Program Files` after verifying `worker.manifest.json` SHA-256.<br>2. Inside the worker, attempt to read `./data/vault.bin` and `./data/cyberpipe_master.db` $\rightarrow$ assert OS kernel `UnauthorizedAccessException` (`0` bytes read).<br>3. Attempt outbound TCP connection $\rightarrow$ assert `SocketException`.<br>4. Send a `0x7FFFFFFF` Protobuf length header over Contour 2 $\rightarrow$ assert `BrainstemSupervisor` rejects before allocation.<br>5. Feed a `300 MB` PDF allocation bomb to Pool B $\rightarrow$ assert worker killed in `<= 15 s` and `CyberPipe.exe` heap delta `< 5 MB`. |
| **`TEST-005`** {#test-005} | **Red-Team Prompt Injection (`HardToolStripper`) & Egress `CentralDataSanitizer` Benchmark** (`CyberPipe.Security.Tests`) | `REQ-005`, `REQ-006`, `QAS-007`, `QAS-008`, `THREAT-001`, `THREAT-003`, `THREAT-007`, `ADR-0006` | 1. Feed 50 indirect prompt-injection payloads tagged `OriginTrustLevel.UntrustedExternal` into `PipelineOrchestrator` and assert `ChatOptions.Tools` is empty (`0` tool invocations).<br>2. Run `CentralDataSanitizer.SanitizeForCloud()` over a `4 KB` corpus containing vault secrets, `sk-`/`ghp_` tokens, Luhn credit cards, SSNs, emails, and file paths $\rightarrow$ assert `100%` redaction in `p99 < 0.5 ms` and `0` placeholder rehydrations on response. |
| **`TEST-006`** {#test-006} | **Contour 1 Named Pipe `FirstPipeInstance`, Anti-Squatting & 8-Client Latency Test** (`CyberPipe.Integration.Tests`) | `REQ-016`, `QAS-004`, `RISK-009`, `THREAT-004`, `ADR-0005` | 1. Pre-create a squatter pipe on `\\.\pipe\CyberPipe.Ipc.{User}` and assert `CyberPipe.Host` aborts startup.<br>2. Start `CyberPipe.Host` normally and run 8 concurrent `cyberpipe status --json` Native AOT processes $\rightarrow$ assert `100%` success, cold start `< 15 ms`, and IPC round-trip `p95 < 25 ms`. |
| **`TEST-007`** {#test-007} | **`Tier 0/1` Routing Latency (`BenchmarkDotNet`) & Cross-DB `L2` Cache Invalidation Test** (`CyberPipe.Benchmarks`) | `REQ-003`, `QAS-001`, `QAS-002`, `RISK-010`, `RISK-011`, `RISK-015`, `ADR-0001` | 1. Benchmark `Tier 0` regex/Aho-Corasick routing $\rightarrow$ assert `p99 < 1.0 ms` and `0` tokens.<br>2. Benchmark `Tier 1` ONNX `all-MiniLM-L6-v2` inference (`p95 < 15 ms`) and SIMD cosine search over `10,000` 384-d vectors (`p99 < 1.5 ms`).<br>3. Mutate `crm.db` and assert `L2 SemanticResponseCache` immediately invalidates cached CRM responses (`0%` stale reads). |
| **`TEST-008`** {#test-008} | **Emergency `/stop` Preemption Latency (`< 50 ms`) & Job Object Termination Test** (`CyberPipe.Integration.Tests`) | `REQ-004`, `QAS-003`, `RISK-015`, `THREAT-014`, `ADR-0008` | Launch an active `Tier 3` task with a streaming mock LLM socket and a child process in a Windows Job Object; send `/stop` and assert all `CancellationTokenSource` tokens, sockets, and OS child processes terminate within **`p99 < 50.0 ms`**. |
| **`TEST-009`** {#test-009} | **`Netrunner` DAG WAL Crash Recovery, `HITL` Pause & `InFlightOperations` Test** (`CyberPipe.Integration.Tests`) | `REQ-010`, `REQ-013`, `QAS-011`, `THREAT-002`, `THREAT-015`, `ADR-0007`, `ADR-0008` | 1. Run a 4-node DAG until it pauses at Node 3 (`HitlApprovalNode`), kill the host process, restart, submit a valid signed `HITL` approval, and assert Nodes 1 & 2 are **not** re-run while Node 4 completes.<br>2. Assert forged/expired `HITL` tokens are rejected (`THREAT-002`).<br>3. Simulate a crash during a `SideEffecting` operation in `InFlightOperations` (`cyberpipe_master.db`) and assert startup transitions it to `InterruptedRequiresConfirmation`. |
| **`TEST-010`** {#test-010} | **`TokenBudgetGovernor` Concurrent Race & Turn Loop-Breaker Test** (`CyberPipe.Unit.Tests`) | `REQ-009`, `QAS-009`, `THREAT-013`, `ADR-0008` | 1. Set remaining `DailyLimitUsd = $0.05` (1 call worth) and fire 10 concurrent cloud LLM requests $\rightarrow$ assert atomic `budget.db` reservation allows **at most 1** paid call and routes the remaining 9 to local `Ollama`.<br>2. Simulate an infinite tool-calling LLM and assert execution halts at `Turn == 3` (Cloud) and `Turn == 5` (Local). |
| **`TEST-011`** {#test-011} | **Loopback `Hangfire` `OTT` Single-Use Auth, DNS Rebinding & Encrypted `hangfire.db` Test** (`CyberPipe.Security.Tests`) | `REQ-011`, `RISK-005`, `THREAT-005`, `ADR-0005`, `ADR-0007` | 1. Assert `GET http://127.0.0.1:5080/hangfire` without `OTT` returns `401`.<br>2. Generate a `60 s` `OTT`, consume it once (`302` + `SameSite=Strict` cookie), replay the same `OTT` a second time, and assert `401`.<br>3. Send `Host: attacker-rebind.com:5080` and assert `400 Bad Request`. |
| **`TEST-012`** {#test-012} | **Event-Driven `SystemResourceMonitor` Overhead (`< 0.1%` CPU) & `1 GB -> 30 KB` Log Compression Test** (`CyberPipe.Benchmarks`) | `REQ-011`, `REQ-012`, `QAS-012`, `ADR-0008` | 1. Measure `SystemResourceMonitor` over a 10-minute idle window and assert CPU usage `< 0.1%` and daemon working set `< 150 MB`.<br>2. Feed a synthetic `1 GB` `.jsonl` log file with repeated stack traces into `LogCompressor` and assert output digest size `<= 35 KB`. |
| **`TEST-013`** {#test-013} | **`ArchUnitNET` 16-Project DAG, Banned Package & `./worker/` Publish Layout Gate** (`CyberPipe.Architecture.Tests`) | `REQ-001`, `QAS-013`, `RISK-002`, `RISK-004`, `THREAT-009`, `ADR-0001` | 1. | **`TEST-014`** {#test-014} | **Hardware Acoustic Safety (`VolumeClamp <= 60%/25%` & Pre-Playback Mic Guard) Test** (`CyberPipe.Unit.Tests`) | `REQ-012`, `QAS-014`, `RISK-012`, `THREAT-014` | 1. | **`TEST-015`** {#test-015} | **`DevToolProcessRunner` Git Hook Neutralization & `./data/` `Deny` ACL Test** (`CyberPipe.Sandbox.Tests`) | `REQ-014`, `RISK-007`, `THREAT-016`, `ADR-0004` | 1.
