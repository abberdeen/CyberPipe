## 1. Executive Summary of Technology Audit Findings

Because `CyberPipe.slnx` currently contains **`0` `.csproj` files and `0` `.cs` files (`RISK-004`)**, all technologies are currently **Unimplemented in Code**. Our audit of [`03-tech-stack-libraries.md`](../../plans/03-tech-stack-libraries.md) and [`17-adr-mvp.md`](../../plans/17-adr-mvp.md) discovered **four critical package/compatibility incompatibilities** that must be corrected before writing `.csproj` files:

1. **`MassTransit.SqlTransport.Sqlite` (`REJECTED — DOES NOT EXIST`):** Specified in `03-tech-stack-libraries.md` L46 and `17-adr-mvp.md` `ADR-001`. MassTransit only provides SQL Transport for PostgreSQL and SQL Server (`RISK-001`). **Replacement (`ADR-0002`):** `MassTransit` `8.x` (`InMemory`) + custom Dapper/SQLCipher Transactional Outbox in `masstransit.db`.
2. **`Microsoft.Data.Sqlite` Metapackage (`BANNED — NATIVE BINARY COLLISION`):** Pulls `SQLitePCLRaw.bundle_e_sqlite3` (unencrypted), which collides with `SQLitePCLRaw.bundle_e_sqlcipher` and causes `Password=...` to be silently ignored (`RISK-002`). **Replacement (`ADR-0003`):** `Microsoft.Data.Sqlite.Core` + `SQLitePCLRaw.bundle_e_sqlcipher`.
3. **`Hangfire.Storage.SQLite` (`BANNED — DRIVER & LOCK CONFLICT`):** Pulls `sqlite-net-pcl` + `bundle_green` (unencrypted), cannot use `ISubsystemDatabaseManager` (`SQLCipher`), and suffers from `SQLITE_BUSY` errors (`RISK-005`). **Replacement (`ADR-0007`):** Custom Dapper/SQLCipher `JobStorage` (or `Cronos` + SQLite table) in `hangfire.db`.
4. **In-Memory `Microsoft.CodeAnalysis.CSharp.Scripting` inside `64 MB` Sandbox (`REJECTED IN WORKER — OOM`):** Roslyn scripting requires `150–300 MB` RAM and will immediately crash with `OutOfMemoryException` inside a `64 MB` Job Object (`RISK-003`). **Replacement (`ADR-0007`):** Run Roslyn on the **host** during `NetrunnerPackageValidator` to pre-compile scripts into restricted `.dll` / `.wasm` modules.
