# 01. Фундаментальные архитектурные принципы CyberPipe

**Платформа:** .NET 10  
**Тип системы:** Автономный мультиагентный оркестратор с моделью Zero-Trust, шиной гарантированной доставки сообщений и кроссплатформенным UI на Avalonia.  
**Вдохновлен:** OpenClaw, но с жестким разделением привилегий, инспекцией безопасности и отказоустойчивостью enterprise-уровня.

---

### 1. Zero-Trust Agent Mesh (Модель нулевого доверия к агентам)
* **Агенты без прямого доступа:** Ни один рабочий агент (воркер: Coder, Researcher, DataParser и т.д.) не имеет прямого доступа к файловой системе, терминалу, сети, базам данных или песочницам.
* **Proposal-based подход:** Агенты формируют только предложения к выполнению действий (**Tool Execution Proposals**).
* **Единая точка авторизации:** Единственный компонент, имеющий право авторизовать и отправить действие на исполнение, — **CEO / Orchestrator Agent**.

---

### 2. Обязательная инспекция безопасности (SecurityAgent)
* **Инспекция каждого шага:** Все предложения (proposals), а также ответы LLM могут быть переданы на анализ специализированному агенту-инспектору (**SecurityAgent**).
* **Не блокирует, а оценивает:** Роль SecurityAgent — выявить риски, проверить ссылки, IP-адреса, проанализировать скрипты (AST-анализ) и выдать структурированный отчет с уровнем риска (**Risk Score & Findings**), а также записать аудит-лог.
* **Human-in-the-Loop:** При обнаружении критических или высоких рисков CEO Agent запрашивает явное подтверждение у оператора через UI.

---

### 3. Отказоустойчивость и гарантированная доставка (No Message Loss)
* **Надежный брокер (RabbitMQ + MassTransit):** Взаимодействие между Gateway, Router, CEO Agent и очередями выполнения происходит через персистентные очереди брокера.
* **Transactional Outbox Pattern:** Исключена рассинхронизация между базой данных и шиной сообщений.
* **Dead Letter Exchanges (DLX):** При сбое узла или перезапуске системы ни одно входящее сообщение или команда не теряется — всё повторно обрабатывается после восстановления.

---

### 4. Строгая изоляция UI (Avalonia 11+ Multiplatform)
* **Кроссплатформенность:** Единый UI-клиент на **Avalonia UI** для Windows, macOS, Linux и Web (WebAssembly).
* **Zero Direct Dependencies:** Проект UI **не имеет прямых ссылок** на библиотеки бизнес-логики (`Core`, `Engine`, `Storage`, `Agents`).
* **Защищенный периметр:** Взаимодействие идет исключительно через контрактную сборку `CyberPipe.Contracts` по защищенному протоколу (gRPC over HTTP/2 с TLS 1.3 + mTLS/JWT Auth).
