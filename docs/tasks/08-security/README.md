# 08-security — Безопасность

## Назначение области

Область отвечает за защитные механизмы локального персонального ассистента CyberPipe (.NET 10) с единственным владельцем (Owner, роли Guest нет):

- предотвращение необратимого уничтожения данных (anti-wipe);
- эвристическую оценку риска аудио/контента перед воспроизведением без фиксированного ограничения громкости;
- очистку исходящих данных перед отправкой во внешние системы;
- авторизацию только Owner по белому списку во всех каналах.

Канон: [DECISIONS.md](../../plans/DECISIONS.md) (Q13, Q17, Q18) и [17-adr-mvp.md](../../plans/initial_arch/17-adr-mvp.md). Устаревшие положения заменены: Guest удалён (только Owner), фиксированный Volume Clamp 60%/25% отменён в пользу эвристической оценки риска, DevTools/Git/Build-навыки удалены и в область не входят.

## Общие принципы

- Одна PostgreSQL + pgvector; Quartz.NET — в той же PostgreSQL. Область не создаёт отдельных хранилищ и не фиксирует брокер сообщений: обмен — только через собственные интерфейсы из TASK-002 с заменяемым транспортом.
- Цепочки только `Trigger -> Skill -> Script -> Delivery` (триггеры: Webhook, Cron, function call, chat). Защитные проверки встраиваются вызывающими сторонами через контракты, а не через визуальный редактор (его нет).
- Sandbox исполнения скриптов (Restricted Token + Job Object + Deny-ACL, конфигурируемый лимит памяти) — TASK-023; данная область sandbox не реализует, а дополняет его политиками на уровне операций и данных.
- HITL-подтверждения (Telegram/Avalonia) — механизм TASK-046; задачи области только возвращают решение вида «требуется подтверждение», не рендерят UI.
- Модели не встроены. Для Tier 1 при первом запуске предлагается стандартный мультиязычный эмбеддинг `multilingual-e5-small`; локальные модели (например Qwen3 через Ollama) устанавливает UI-инструмент TASK-081, каталоги 15 локальных + 8 облачных JSON — TASK-080. Задачи области модели не устанавливают.
- Токен-бюджет по умолчанию $0.50/день, 4000/12000 токенов, 3 облачных / 5 локальных ходов — всё конфигурируемо (применение — TASK-033). Задачи области бюджет не реализуют.
- Все пороги, списки и лимиты конфигурируемы (TASK-003); значения по умолчанию — цели, а не ворота. SLO — целевые ориентиры, не блокирующие критерии приёмки.
- Код пока отсутствует (`CyberPipe.slnx` пуст); пути проектов помечены «к созданию» (to-be-created), команды `dotnet build/test` — плановые стандартные команды .NET 10.
