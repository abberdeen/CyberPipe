# 06-skills — Навыки (Skills)

## Назначение области

Навыки — исполняемые способности CyberPipe, вызываемые из цепочек вида `Trigger -> Skill -> Script -> Delivery` и напрямую через маршрутизацию Tier 0–3. В этой области нет DevTools/Git/Build-навыков (удалены по решению Q14) и нет роли Guest — только Owner.

## Состав

| ID | Задача | Назначение |
|---|---|---|
| TASK-050 | Хост-навыки: медиа, система | Медиа/громкость/статус/таймеры на хосте Windows |
| TASK-051 | Персональные навыки | Заметки, финансы, напоминания, CRM |
| TASK-052 | Голос: Whisper | Локальное распознавание речи (STT) |
| TASK-053 | Знания: второй мозг | Семантический поиск и память по заметкам/документам |

## Общие принципы

- Все навыки реализуют контракты из TASK-002; пакеты скриптов имеют точку входа `skill-hack.*` и `netrunner.manifest.json` (`runtime.language`, `runtime.languageVersion`, `runtime.environment`, `runtime.environmentVersion`, `entrypoint`) — валидация манифеста относится к TASK-042, здесь не дублируется.
- Данные — только одна PostgreSQL + pgvector (TASK-010/TASK-011); отдельной БД или брокера у навыков нет, транспорт сообщений — собственные заменяемые интерфейсы из TASK-002.
- Модели не встроены: установка/настройка локальных моделей — TASK-081, каталоги — TASK-080; навыки получают готовый клиент модели через DI и работают на моках до готовности модельных задач.
- Безопасность: эвристическая оценка риска контента/аудио — TASK-071, здесь навыки лишь передают ей вход и учитывают вердикт; песочница Restricted Token + Job Object + Deny-ACL — TASK-023.
- Код пока отсутствует (`CyberPipe.slnx` пуст); пути проектов помечены как «to-be-created», команды `dotnet build/test` — плановые стандартные команды .NET 10.

## Порядок реализации

1. TASK-050 — без зависимостей от данных, только контракты и хост.
2. TASK-051 и TASK-053 — после схемы данных (TASK-011), TASK-053 также после хранилища эмбеддингов (TASK-012).
3. TASK-052 — параллельно, на фейковом STT-движке до подключения реальной модели.
