# 09-models — Каталоги моделей, установщик и советник по железу

## Назначение области

Область отвечает за работу CyberPipe (.NET 10) с моделями без встраивания моделей в приложение: курируемые каталоги в виде JSON (15 локальных + 8 облачных), инструмент установки и настройки локальных моделей для новичка (например Qwen3 через Ollama) и советник совместимости моделей с железом ПК.

Канон: [DECISIONS.md](../../plans/DECISIONS.md) (Q10, Q15, Q16) и [17-adr-mvp.md](../../plans/initial_arch/17-adr-mvp.md) (ADR-007). Детальный исходный материал по советнику и каталогам: [13-model-advisor-and-tier-configuration.md](../../plans/initial_arch/13-model-advisor-and-tier-configuration.md); при расхождении с DECISIONS.md и ADR-007 верны DECISIONS.md и ADR-007 (в частности, число облачных моделей — 8, а не расширенные списки из раздела 4 документа 13).

## Общие принципы

- В приложение ничего не встроено, включая эмбеддинг (Q15): ни веса моделей, ни рантайм Ollama не поставляются в составе сборки. При первом запуске мастер (TASK-063) предлагает установку стандартного мультиязычного эмбеддинга `multilingual-e5-small` для Tier 1 (Q10, вариант А); фактическую установку выполняет инструмент TASK-081, каталог описывает TASK-080.
- Приложение не связано с конкретными моделями: пользователь сам выбирает модель на каждый ярус (Tier 1 эмбеддинг, Tier 2 лёгкая LLM, Tier 3 тяжёлая LLM). Каждая привязка хранит явный признак локальная/облачная (`ModelHostingType`: `Local` / `RemoteCloud` из контрактов TASK-002); назначение по ярусам потребляют роутеры TASK-031/TASK-032 и TokenBudgetGovernor TASK-033.
- Каталоги — жёсткие курируемые списки 15 локальных + 8 облачных, ведутся только как JSON-файлы (Q16). Расширение каталога — правка JSON и его версии, а не кода; произвольная модель вне каталога вводится пользователем вручную (Endpoint / ModelId / ApiKey) вне этой области.
- Облачные модели платные и попадают под TokenBudgetGovernor (TASK-033): по умолчанию дневной кап $0.50, soft 4000 / hard 12000 токенов, 3 облачных / 5 локальных ходов, всё конфигурируемо (Q23). Локальные модели стоят $0.00 за токены. Эта область губернатора не реализует, а только поставляет ему признаки `Local`/`RemoteCloud` и цены из каталога.
- Установка локальных моделей — только с явного действия владельца (только Owner, роли Guest нет, Q18). Скачивание весов и установка рантайма без подтверждения пользователя не выполняются; HITL-механизм при этом не используется (подтверждение — внутри самого UI-инструмента).
- Одна PostgreSQL + pgvector — единственное хранилище состояния (Q2/Q21): выбранные назначения моделей и состояние установок сохраняются через контракты/репозитории области данных, а не в локальных файлах состояния. Сами JSON-каталоги — поставляемые с приложением справочные данные только для чтения.
- Код пока отсутствует (`CyberPipe.slnx` пуст); пути проектов помечены «to-be-created», команды `dotnet build/test` — плановые стандартные команды .NET 10.

## Порядок реализации

1. TASK-080 — каталоги и валидатор: фундамент области, от неё зависят обе остальные задачи.
2. TASK-082 — советник по железу поверх каталога TASK-080 (не зависит от установщика).
3. TASK-081 — установщик/UI поверх каталогов TASK-080; вердикты советника TASK-082 показывает как потребитель его контрактов, но реализует установку и без него (на фейке советника).
