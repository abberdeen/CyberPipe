# TASK-081 — Инструмент установки и настройки локальных моделей (Ollama)

## Цель

Дать владельцу-новичку UI-инструмент, который сам ставит и настраивает выбранную локальную модель: проверяет и при согласии устанавливает рантайм Ollama, скачивает веса выбранной модели из каталога TASK-080 (например Qwen3), применяет безопасные параметры запуска и проверяет модель пробным запросом — без ручных команд в терминале.

## Контекст

- Канон: [DECISIONS.md](../../plans/DECISIONS.md) (Q15) и [17-adr-mvp.md](../../plans/initial_arch/17-adr-mvp.md) (ADR-007): в интерфейсе должен быть инструмент установки и настройки локальных моделей для новичка — «выбрал Qwen3 через Ollama — приложение само ставит и настраивает». Модели и рантайм в приложение не встроены.
- Тот же инструмент выполняет установку стандартного эмбеддинга `multilingual-e5-small` для Tier 1, когда владелец принял предложение при первом запуске (мастер TASK-063 только предлагает; ставит эта задача). Эмбеддинг — локальная ONNX-модель, Ollama для неё не требуется.
- Кандидаты на установку берутся только из каталога TASK-080 (`IModelCatalog`, `hostingType = Local`); произвольный тег модели вне каталога здесь не вводится (ручной ввод облачной модели — вне рамок, см. ниже).
- Вердикт советника по железу (TASK-082) инструмент показывает рядом с моделью, если советник доступен, но установка им не блокируется жёстко: при вердикте «мало памяти» требуется дополнительное явное подтверждение владельца с показом риска (свопинг/фризы). Зависимости от TASK-082 нет — в тестах и при недоступности советника используется его фейк/отсутствие вердикта.
- Установка — действие только Owner (роли Guest нет, Q18) и только по явному нажатию; фоновых скачиваний без ведома владельца нет. Скачивание идёт по сети наружу — список адресов (рантайм, реестр моделей) фиксируется в конфигурации инструмента, а не хардкодится по коду.
- Точка входа в UI — экран моделей Desktop (TASK-061 даёт переход и показ текущих назначений); эта задача поставляет экран/диалог установщика и его ViewModel как компонент, встраиваемый в Desktop, и не зависит от TASK-061.

## Объём работ

1. Сервис установки рантайма (to-be-created, например `ILocalRuntimeInstaller`): обнаружение Ollama (наличие исполняемого файла/службы, запрос локального API `localhost:11434` — адрес и порт из конфигурации TASK-003), определение установленной версии; если рантайма нет — по подтверждению владельца: скачивание официального дистрибутива Ollama для текущей ОС, установка, ожидание готовности API. Фокус ручного тестирования — Windows; на прочих ОС без доступного дистрибутива — честное состояние «установите Ollama вручную» со ссылкой-инструкцией текстом, без падения.
2. Сервис установки моделей (to-be-created, например `ILocalModelInstaller`):
   - список уже установленных локальных моделей (запрос рантайма), сопоставление с каталогом TASK-080 по `modelId`;
   - установка выбранной модели: скачивание весов через API рантайма с прогрессом (процент, скачано/всего, скорость при наличии), отмена по кнопке, докачка/повтор после обрыва средствами рантайма;
   - удаление установленной модели по подтверждению;
   - применение параметров запуска по умолчанию из каталога: `defaultContextTokens` (безопасное окно контекста, по умолчанию 8192) вместо паспортного максимума, чтобы не раздувать KV-Cache;
   - пробный запрос после установки (короткая генерация/эмбеддинг) — модель считается установленной только после успешной проверки; назначение модели на ярус этим пробным запросом не выполняется (назначение — выбор пользователя, хранится как `TierModelAssignment` из TASK-002).
3. Установка стандартного эмбеддинга: скачивание ONNX-файлов `multilingual-e5-small` из настроенного источника, проверка целостности (размер/хеш из дескриптора каталога при наличии), размещение в каталоге данных приложения, регистрация локального ONNX-провайдера эмбеддингов для Tier 1 (потребитель — TASK-031). Повторная установка уже установленного эмбеддинга — no-op с показом «уже установлен».
4. Avalonia UI инструмента (to-be-created, компонент для Desktop): список локальных моделей каталога сгруппирован по Tier 2 / Tier 3; у каждой — размер `q4SizeGb`, минимум RAM, вердикт советника (если есть), состояние (не установлена / скачивается N% / установлена / ошибка); кнопки «Установить», «Отменить», «Удалить», «Проверить»; отдельный блок эмбеддинга Tier 1 с его состоянием. Все состояния — из ViewModel на контрактах, View не ходит в сеть и не запускает процессы сама.
5. Ошибки и отмена: нет сети, нет места на диске (предварительная проверка свободного места >= `q4SizeGb` с запасом), рантайм не поднялся, пробный запрос упал — каждое состояние показывается понятным текстом с кнопкой «Повторить»; частично скачанная модель не помечается установленной. Операции не требуют прав администратора сверх тех, что запросит сам дистрибутив Ollama; запрос повышения прав приложением самостоятельно не инициируется.
6. Состояние установок не хранится в локальных файлах состояния: источник правды — сам рантайм (список моделей) и ONNX-каталог приложения; выбранные назначения по ярусам сохраняет область данных через контракты TASK-002.

## Вне рамок

- Каталоги моделей и их наполнение (TASK-080); вердикты совместимости и проба железа (TASK-082).
- Мастер первого запуска целиком (TASK-063): здесь только вызываемая им операция «установить эмбеддинг/модель».
- Назначение моделей на ярусы как пользовательский сценарий выбора (экран Desktop TASK-061, роутеры TASK-031/TASK-032) и подсчёт бюджета (TASK-033).
- Облачные модели: ввод Endpoint / ModelId / ApiKey, проверка облачных ключей, хранение секретов (TASK-003, TASK-061).
- Поддержка рантаймов, отличных от Ollama (LM Studio и т.п.), и ручной ввод тега модели вне каталога.
- Обновление Ollama поверх установленной версии по расписанию; допустима только установка при отсутствии и показ установленной версии.

## Контракты и интерфейсы

- Потребляет из TASK-002: `ModelDescriptorDto` и `TierModelAssignment` (только чтение кандидатов и фиксация факта установки), `Result<T>`/`ErrorDto` для исходов операций.
- Потребляет из TASK-080: `IModelCatalog` — список локальных моделей (`hostingType = Local`), их `modelId`, `q4SizeGb`, `defaultContextTokens` и дескриптор эмбеддинга `multilingual-e5-small`.
- Поставляет: `ILocalRuntimeInstaller` (обнаружение/установка/версия Ollama), `ILocalModelInstaller` (список установленных, установка с прогрессом и отменой, удаление, пробный запрос, установка эмбеддинга), ViewModel экрана установщика для Desktop (TASK-061) и мастера (TASK-063). Прогресс — через контрактный DTO прогресса/поток событий контрактов TASK-002, без типов HTTP-клиента Ollama в публичных сигнатурах.
- Адреса скачивания (дистрибутив Ollama, ONNX эмбеддинга), порт локального API и каталог данных приложения — конфигурация TASK-003, не константы в коде.

## Результаты

- Сервисы установки рантайма и моделей (to-be-created): на чистой Windows-машине без Ollama владелец из UI ставит Ollama, затем Qwen3 из каталога, и модель проходит пробный запрос.
- Установка `multilingual-e5-small` одной операцией, пригодная для вызова из мастера первого запуска (TASK-063).
- Avalonia-компонент установщика (to-be-created) со всеми состояниями из п. 4 «Объём работ», встраиваемый в экран моделей Desktop.

## Критерии приёмки

- Нет Ollama: инструмент показывает «не установлен», по кнопке и подтверждению ставит рантайм и дожидается готовности его локального API; при неудаче — понятная ошибка и кнопка «Повторить», приложение не падает.
- Установка модели из каталога: виден прогресс, отмена останавливает скачивание, модель не помечена установленной; повторная установка после обрыва завершается и пробный запрос проходит.
- Установленная модель запускается с `defaultContextTokens` из каталога (по умолчанию 8192), а не с паспортным максимумом контекста.
- Эмбеддинг: после установки `multilingual-e5-small` пробный эмбеддинг-запрос возвращает вектор размерности из дескриптора каталога; повторная установка — no-op «уже установлен».
- Нехватка места на диске и отсутствие сети определяются до/во время скачивания и показываются текстом; частично скачанная модель установленной не считается.
- При вердикте советника «мало памяти» (фейк TASK-082) установка требует дополнительного подтверждения с текстом риска; без советника установка не блокируется.
- UI не зависает во время скачивания: прогресс и отмена отзывчивы (операции — асинхронные, не на UI-потоке).

## Тестирование

- Уровень: unit + component; интеграционный — вручную на Windows.
- Как: unit — ViewModel и сервисы на фейках `IModelCatalog` (TASK-080), `ILocalRuntimeInstaller`/HTTP-рантайма (фейковый локальный API Ollama: список моделей, прогресс pull, обрыв, отмена, пробная генерация) и фейке советника TASK-082; component — UI инструмента на полном наборе фейков без сети и реальной Ollama (Avalonia.Headless). Интеграционная ручная проверка на Windows: чистая машина -> установка Ollama -> Qwen3 -> пробный запрос; установка эмбеддинга -> пробный вектор. Реальные скачивания в автотесты не ходят.
